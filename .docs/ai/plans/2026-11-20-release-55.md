# Release 55 Implementation Plan (Track A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. If those skills are not installed, do the tasks in order as written. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build 55 reaches TestFlight on iPhone, iPad and Mac by 2026-12-03 with honest on-screen copy, and the App Store listing is ready to submit by 2026-12-17.

**Architecture:** No feature work. Five strings change so delete dialogs say what deleting does. The Mac gets what it lacks to ship: an app icon, a Help menu item that works, a release script and an archive check. The store text, screenshots and website are brought in line with the app as built.

**Tech Stack:** Swift 6 / SwiftUI, XcodeGen (the Xcode project is generated and gitignored: run `xcodegen generate` after adding any file), bash release scripts with shell tests in `scripts/tests/` (run them with `bash scripts/tests/<name>.sh`; most are not executable), a SvelteKit static site on Cloudflare (`web/`), App Store Connect.

**Spec:** `~/git/seedkeep/.docs/ai/phases/2026-11-20-v1-plan.md` (sections 2–6). Release rules: `.docs/ai/app-store-submission-notes.md`.

## Global Constraints

- This checkout (`~/git/seedkeep-ios`) and branch `redesign/r2-design-system` belong to Track A until task A9 merges to `main`. After A9, `main` is the only release branch and `redesign/r2-design-system` is never released from again.
- Version 1.0.0. Build 55 for iPhone/iPad and for Mac (the same number). Build 56 is reserved for Track B. A re-cut takes the next unused number (`project.yml` `CURRENT_PROJECT_VERSION` plus 1) and needs a changelog entry for that number first; if 55 has to be re-cut before Track B ships, tell the owner, because Track B then becomes 57.
- Bundle ID `app.seedkeep.ios`, team `K7CBQW6MPG`, iCloud container `iCloud.app.seedkeep`, CloudKit environment Production. Minimum OS 27.0 on every platform.
- No new features, no CloudKit schema change, no third-party packages.
- Each external action needs the owner's go-ahead at the time, and a go-ahead covers one action: a push; the merge to `main`; a signed archive (it can create certificates and profiles); each upload; a website deploy; anything in App Store Connect or the developer portal.
- Gate: `scripts/test-gate.sh --simulator-udid DD9BE2B2-F191-459F-8B5B-1AD8B252B171`. Baseline to meet or beat: Kit 25, CloudKit 176, iOS 1,449, Mac 1,464. `release.sh` runs the gate again with no simulator argument, so always start it as `SIM_UDID=DD9BE2B2-F191-459F-8B5B-1AD8B252B171 ./scripts/release.sh`.

- Focused Swift test: `xcodebuild test -project Seedkeep.xcodeproj -scheme Seedkeep -destination 'platform=iOS Simulator,id=DD9BE2B2-F191-459F-8B5B-1AD8B252B171' -only-testing:SeedkeepTests/<SuiteStructName>`. A run that executed zero tests is a failure.
- Mac build check: `xcodebuild build -quiet -project Seedkeep.xcodeproj -scheme Seedkeep -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO`.
- Before each commit that touches Swift, a script, an entitlement or a plist: a Codex `gpt-6.1-terra` diff review and an independent Sonnet review (umbrella plan, section 5). Doc-only commits need none.
- The Mac fallback: if no Mac build 56 is uploaded, processed and installable from TestFlight by 2026-12-10 (a Mac build 55 does not count), stop Mac work for 1.0 and follow "If the Mac fallback is taken" in the umbrella plan, section 4.

## Review Focus

1. **Someone deletes a bed, or bulk-deletes seeds on the Mac, and loses a year of journal.** Every delete dialog must say the linked plantings and journal entries go too. Task A2.
2. **A Mac archive that passes here but is rejected at upload.** The verifier checks the Mac bundle layout, sandbox, Production iCloud, icon, privacy manifest, category and export-compliance key before export. Task A6.
3. **`release.sh` refusing to run on release day** because of an untracked file, or running its tests on the wrong simulator. Tasks A1 and A9.
4. **App Review reading store text that promises something the app does not do** (sharing, barcode scan, iPhone export). Task A8.
5. **Build numbers colliding**: a failed run that used up 55, or Track B cutting 55 again. Tasks A9 and B6.
