## Verified environment and limits

and only iOS 27.0 / 27.2 simulator runtimes. DD9 belongs to iOS 27.0; the
preserved prior audit metadata independently records 27.0 (24A434). The old
report's SDK/runtime wording is corrected from that primary metadata.
A newer SDK and a 26.0 deployment target do not prove execution on OS 26.

Internal free space was about 14 GiB before checks; no external storage was
mounted. A scoped read-only inventory found about 5 GiB of generated Seedkeep
build/index caches, including historical compiled products and at least one
raw result bundle that must be preserved. Nothing was deleted. No existing
simulator was erased, moved to another runtime, or repurposed.

Apple documents [version-specific simulator downloads](https://developer.apple.com/documentation/xcode/downloading-and-installing-additional-xcode-components).
This pass did not verify the current 26.0 download catalog, installation peak
space or install a runtime. A genuine macOS 26 check needs a Mac running 26
or a compatible, separately provisioned [macOS VM](https://developer.apple.com/documentation/virtualization/installing-macos-on-a-virtual-machine).
No restore image was downloaded, VM created, host downgraded, or external
compute purchased/used. After this inventory, the owner chose “os 27 is good
enough.” The accepted scope uses existing OS 27 evidence while retaining the
declared 26.0 floors; this is not a claim of actual OS 26 execution.
