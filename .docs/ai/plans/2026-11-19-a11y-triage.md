# 1.0 accessibility triage and sharing hidden — 2026-11-19

Umbrella decision 2026-11-19: accessibility is triaged for 1.0, not driven
to zero, and owner-started iCloud sharing is hidden.

## Blocker rules

Fix only:
- a control with no usable accessible label;
- text whose rendered contrast is below 3:1;
- text clipped so that core-flow information (Seeds, Add Seed, Seed Detail,
  Journal entry, Today) is lost, with no other way to read it;
- core-flow text that does not scale with Dynamic Type.

Allowlist everything else with an evidence-based reason.

## Input

The 2026-11-18 main audit: 319 unallowlisted callbacks, which collapse to
74 distinct groups (by destination, type, identifier, label and element
type). Each callback was matched to its issue text and screenshots through
the xcresult attachment manifest. The 166 callbacks that name an element
have an element screenshot, and the 153 with no element have none.

## Method

Five reviewers, one per area (Today, Settings, Garden, Seeds, Journal),
read the screenshots and view source and classified every group. A
sceptic per area then tried to overturn each call. The sceptics overrode
nothing. The lead spot-checked the bed grid (`BS`/`D1`) and Settings
clipping screenshots and agreed.

| Category | Groups | Callbacks |
|---|---:|---:|
| Sampling artifact (palette text under glass bars or at the scroll edge) | 29 | 95 |
| Scales with a text style | 14 | 73 |
| Unresolved element (no element named; screenshot reviewed) | 12 | 81 |
| System control (Liquid Glass toolbar buttons, pickers) | 12 | 44 |
| Row labels that wrap, flagged as clipped | 5 | 18 |
| Intentional one-line preview (full text in Square details) | 1 | 2 |
| Hidden for 1.0 (Share garden via iCloud) | 1 | 6 |

The palette backs the contrast calls. Text tokens `ink`, `muted`,
`accent` and `warn` measure at least 4.5:1 on every surface in both
modes. `faint` is 3.16–3.81:1 in light mode, and `verdictTooLate` falls
below 3:1, but that colour is used only for status-dot fills, never for
text.

**Result: no 1.0 blocker found. No app UI change for accessibility.**

## Changes

- `FeatureFlags.iCloudSharingEnabled = false` hides only the owner's
  "Share garden via iCloud" button. "Leave shared garden" and accepting
  share links stay. The legacy-invite message no longer points at the
  hidden button.
- Audit allowlist:
  - an entry's checkpoint can be nil, which matches any page;
  - new `.unresolved` element match for findings that name no element;
  - 73 triaged entries covering all four configurations;
  - the 3 entries for the hidden Share button are removed.

## Rerun 1: the contrast check is not repeatable

The first rerun used the same source plus the allowlist above (light/dark
× default/AXXXL on DD9). It still reported 143 callbacks (53 / 49 / 21 / 20),
in 54 groups that were all new. Most of the 2026-11-18 contrast elements
were no longer flagged, and others were flagged in their place:
- palette text in the Seeds rows, Seed Detail and Journal;
- Today's "DUE" and "Sunrise".

All but four of the 54 groups were contrast. The audit's pixel-sampled
contrast check is therefore not repeatable on this app, which is why
allowlisting never converged.

Decision applied:
- **Contrast callbacks are logged as `ADVISORY` and no longer fail the
  audit.** `WorkbenchContrastTests` gates palette contrast (text 4.5:1,
  graphics 3:1) deterministically. Off-palette text uses system label
  colours, which clear 3:1. `SeedRow`'s `.tertiary` text is a "•"
  separator in a view no screen uses.
- The four non-contrast findings got allowlist entries (section F): two
  Settings rows in the body style, plus two element-detection callbacks
  whose screenshots show only text blurred behind glass bars.

## Verification

- Main gate (`scripts/test-gate.sh`, DD9) passed with the sharing change and
  allowlist: Kit 25 / CloudKit 176 / iOS 1,449 / Mac 1,464.
- Audit rerun 2 (`scripts/a11y-audit.sh`, DD9, 1,762 s): **PASS**. All
  four configurations passed with 0 gating findings. 376 callbacks were
  suppressed by the allowlist, and 145 contrast advisories were logged
  (50 / 45 / 24 / 26). Work dir:
  `$TMPDIR/seedkeep-a11y-audit/20261119-103926-79211`.
- One passing run does not prove the result is stable. A future
  non-contrast callback of a new kind would fail the audit and need the
  same triage.

## Not covered

- No manual VoiceOver pass yet; that is a release-checklist item for the
  owner.
- No physical-device check.
- Allowlist entries cover all configurations, so a real regression on an
  allowlisted element in another appearance would be hidden. Recheck
  conditions are recorded on each entry.
