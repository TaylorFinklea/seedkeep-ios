# Climate data sources

`zip_climate.csv` is generated by `scripts/build-climate-resources.py` from the Seedkeep server's ZIP dataset. The script is idempotent: the same source always produces the same bytes. Rebuild it with `python3 -I scripts/build-climate-resources.py`.

- **ZIP codes and coordinates:** U.S. Census Bureau, ZCTA Gazetteer 2024 (public domain).
- **USDA hardiness zones:** USDA Agricultural Research Service, Plant Hardiness Zone Map (2023), <https://planthardiness.ars.usda.gov/>, read through the phzmapi.org mirror.
- **Frost dates:** a zone-level estimate from NOAA 1991–2020 climate normals and horticultural references. The table is `Seedkeep/Core/Climate/ZoneFrostDates.swift`, ported from the server's `ZONE_FROST_FALLBACK`. The dates are not measured for any ZIP, and no accuracy is claimed for them.
- **Build:** 2026-10-20, from the server's `data/zip_locations.csv`: 33,751 ZIP rows across 26 zones.
